# Azure-Projects

This is proof of my learning and hand-on experience in Seneca college where I achieved and completed the projects.

**Project 1**

Deploying a Multi-Region Website in Azure - Seneca College – MST400, Winter 2025 

Designed and launched a company website across two Azure regions (East US and Poland 
Central) for high availability. I configured virtual machines and load balancers in both 
regions, then used Azure Traffic Manager to automatically direct users to the nearest 
location. I tested everything from a remote VM in South Africa to make sure traffic was 
routing correctly and the load balancing was working.

Link: https://youtu.be/5evsm_NvGhE

**Project 2**

Cloud Backup & VPN Solution for Remote Employees - Seneca College – MST400, Winter 2025 

Set up a secure Azure-based backup solution for remote users. I built two virtual networks 
in separate Azure regions and connected them using a Peer-to-Site VPN tunnel. Each user 
had their own folder on a shared drive, and I scheduled automated backups to run weekly 
and monthly with different retention periods. I also tested file restoration from the cloud 
to make sure everything worked as expected.
